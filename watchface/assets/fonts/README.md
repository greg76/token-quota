# Roboto Condensed source

This directory contains the unmodified variable font `RobotoCondensed.ttf` and its SIL Open Font License from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/robotocondensed).

[`../../scripts/generate-clock-font.py`](../../scripts/generate-clock-font.py) selects the Bold weight (700) and produces the bitmap subset under the name **Token Clock**. It contains digits and a colon; the TTF itself is not included in the watch application. Retain `RobotoCondensed-OFL.txt` with the source font.
